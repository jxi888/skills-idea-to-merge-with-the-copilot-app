# 🗺️ Mona's Bookmark Manager Roadmap

A quick look at what we plan to build and what could go wrong in Mona's Bookmark Manager.

## 📊 Summary

| Area | Item | Type | Priority |
| --- | --- | --- | --- |
| Discovery | Search & filter bookmarks | 🚀 Feature | High |
| Editing | Edit a bookmark | 🚀 Feature | High |
| Organization | Tags or folders | 🚀 Feature | Medium |
| Data | Import / export | 🚀 Feature | Medium |
| Data integrity | Duplicate slugs on re-add | 🐞 Bug | Medium |
| Validation | Empty URL accepted | 🐞 Bug | High |
| Persistence | Bookmarks lost when localStorage is cleared | 🐞 Risk | High |

## 🚀 Planned features

- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: high
- 🏷️ Tags or folders — priority: medium
- 📦 Import / export bookmarks — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs on re-add — priority: medium
- 🐞 Empty-URL validation missing — priority: high
- 🐞 Bookmarks lost when localStorage is cleared — priority: high
